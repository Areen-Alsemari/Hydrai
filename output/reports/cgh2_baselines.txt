   class  3 small_slow_leak                NO alarm on its primary signature (pressure fall, inventory): there is no low-pressure or inventory alarm; the H2 alarm (25 %LFL) exists and picks up >= ~1 mm only
   class  4 abnormal_pressure_behaviour    pressure high: PAH / PAHH exist (overrun, blocked relief, fire); the stuck-open discharge valve shows only on the flow meter and inventory: no alarm defined
   class  5 containment_anomaly            H2 detector alarm 25 / 50 %LFL exists
   class  6 structural_concern             strain: NO static alarm defined
   class -1 unknown_anomaly                variable

PROVISIONAL: static-alarm limits are PAH 1.02 x MOP, PAHH 1.05 x MOP (Addendum 1), gas temperature 85/100 C (JUDGE) and hydrogen 25/50 %LFL (INL); no real Saudi alarm settings are public
